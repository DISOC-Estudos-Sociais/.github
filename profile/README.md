# DISOC — Organização de projetos no GitHub

Bem-vindo(a)! Este espaço reúne os projetos da **DISOC — Diretoria de Estudos Sociais (IPECE)** no GitHub. Aqui centralizamos códigos, documentação e o acompanhamento das atividades da equipe. Se você é novo(a) no GitHub, este guia foi feito para ajudar!

---

## Por que usamos o GitHub na DISOC?

O GitHub nos permite:

* Manter histórico de alterações nos arquivos
* Colaborar e revisar mudanças com controle de versão
* Documentar metodologias e rotinas de análise
* Acompanhar demandas de forma organizada com *issues* e *projects*

Nosso objetivo é promover organização, transparência e reprodutibilidade dos projetos.

---

## Repositórios: o que são e o que colocar neles?

Repositórios funcionam como pastas onde guardamos arquivos de um projeto.

👉 No GitHub colocamos **arquivos de texto editável**, como:

* Scripts e códigos (R, Python, Stata, etc.)
* Documentação técnica (`.md`, `.txt`)
* Notebooks e roteiros de análise

Esses arquivos podem ser versionados com facilidade, permitindo colaboração em equipe.

---

## O que NÃO deve ser enviado para o GitHub

📌 Utilize o **Google Drive da DISOC** para armazenar:

* Arquivos do Office (Word, Excel, PowerPoint)
* Bases de dados pesadas
* Dados sigilosos ou restritos
* PDFs muito grandes

Se necessário, você pode incluir um arquivo `.md` no repositório indicando a localização do conteúdo no Drive.

---

## *Issues*: como usar

*Issues* são registros de tarefas, sugestões, dúvidas ou correções relacionadas a um repositório.

Use *issues* para:

* Reportar problemas em códigos
* Solicitar melhorias ou novas funcionalidades
* Registrar demandas do projeto
* Discutir soluções com a equipe

Cada *issue* pode receber:

* Etiquetas (classificação)
* Responsável(is)
* Comentários
* Status de andamento:

  * **A fazer**
  * **Fazendo**
  * **Concluído**

---

## *Project*: acompanhamento dos trabalhos

Os *Projects* organizam as *issues* em quadros (Kanban).

Na DISOC utilizamos o **Project “Acompanhamento”**, que reúne as demandas de diferentes repositórios em um único painel, facilitando:

* Priorização das atividades
* Visualização do fluxo de trabalho
* Responsabilização e prazos

---

## Guia rápido — primeiros passos

1. Acesse a organização **disoc-ipece** no GitHub.
2. Entre no repositório relacionado à sua tarefa.
3. Antes de fazer alterações, verifique as *issues*.
4. Para novos problemas ou solicitações, **abra uma *issue*** com uma boa descrição.
5. Consulte o *Project “Acompanhamento”* para acompanhar o andamento das tarefas.
6. Dados e arquivos grandes → **Google Drive da DISOC**.

---

## Boas práticas

* Utilize mensagens de *commit* claras e objetivas.
* Documente scripts com comentários quando possível.
* Evite arquivos desnecessários ou duplicados.
* Nunca subir dados sensíveis ou informações pessoais.
* Inclua um `README.md` em cada repositório com:

  * Objetivo do projeto
  * Estrutura de pastas
  * Como executar os scripts
