# DISOC no Github

## O que são repositórios?

São como pastas onde são atualizados arquivos, especialmentee arquivos de **texto**, como códigos. Esses repositórios permitem alterações em equipe e principalmente controle de versionamento.

## O que fazer com arquivos que não são texto?

Utilizamos o Google Drive como auxiliar, colocando nele tudo que for do pacote office (word, excel, powerpoint). Bases de dados também não devem ser upadas no github por serem arquivos pesados.

## O que são issues?

São comentários que podem ser feitos no repositório. Abrir uma issue permite que as pessoas que trabalham no repositório acompanhem demandas e sugestões, bem como vincular automaticamente essas demandas a um processo. As issues tem status de acompanhamento (a fazer, fazendo e feito)

## O que é um project?

São paineis de acompanhamento de issues e repositórios. No caso da Disoc, o principal project é o Acompanhamento, onde a maioria dos issues de todos os repositórios da organização estão lá para serem visualizados.
